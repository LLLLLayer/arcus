# 11 · 「重拍」——Apple Spatial Reframing 的轻量端侧复刻

> 受 WWDC 2026「Spatial Reframing」启发(照片拍完后拖动改变机位、AI 补全露出区)。
> 本功能在**不改动既有查看交互**的前提下,新开一个入口复刻其核心交互与两段式补全。
> 交互调研见对话记录;本文记录实现、设计取舍与已知边界。

---

## 1. 入口与隔离原则(不影响旧交互)

编辑页右上角 `perspective` 图标 → 进入「重拍」。所有改动都是**加默认值的开关**,关闭时旧交互逐字节不变:

- `ViewerParams.reframeMode`(默认 `false`):仅重拍为 true;
- `ParallaxRenderer.zoomLevel`(默认 `1`,退出重拍由 `updateUIView` 强制复位);
- 复用**同一个** `ParallaxMetalView` / `ParallaxRenderer`,**不**新建第二个 MTKView ⇒ 无额外开销;
- 双指手势在非重拍态直接 `return`。

## 2. 交互(对齐 Spatial Reframing)

| 手势 | 行为 |
|---|---|
| 单指拖动 | 移动虚拟机位(`parallaxAmp` 0.34,远大于查看的 0.02–0.13),**不回弹**(保持所选机位) |
| 双指捏合 | 缩放(`zoomLevel` 1–3×,乘到 `viewScale`) |
| 双击 | 复位机位 + 缩放 |

`bgParallaxFactor` 在重拍下提到 0.5(查看是 0.2)⇒ **背景活动范围更大**。

## 3. 两段式:预览(便宜) → 确认(补全)

对齐 Apple「实时预览 + 露出区先虚化、确认才生成」:

1. **预览态**:用已烘焙的 scene 实时渲染(便宜);移动后**露出画框的边缘做磨砂虚化**(`ultraThinMaterial` 蒙四周)作占位。
2. **「补全这一视角」**:把当前机位渲染成全分辨率静帧,**用品红哨兵色清屏** ⇒ 渲染后仍是品红的像素 = 被移出画框的精确「洞」掩膜 → 跑 **LaMa**(FFC 擅长外扩)补全 → 出清晰成片。
3. **成片态**:保存到相册 / 重新调整。

桥接见 `ReframeController.snapshot()`(`ParallaxMetalView.swift`):`renderOffscreen(clearColor: 品红)` → `TextureIO.cgImage` → 阈值出洞 → `dilated(2)` 吞 MSAA 边。

## 4. 已知边界(重要)

- **「补全这一视角」只补"画框外被移出去的边"**,**不补"主体正后方"**——主体背后的去遮挡在**处理照片时**就烤进背景层了,其质量取决于当时选的填充模式:
  - 快速(`vertical+depth`)→ 背后是**竖直延伸的条纹**,结构化背景下会糊(实测杯子右后方"奇怪"即此);
  - **重拍强烈建议用「AI 补全」(MI-GAN)或 PatchMatch** 处理,背后才是内容感知纹理。
- 大幅移动会露出很宽的边,单次 512 LaMa 外扩可能偏软/有重复纹理;
- 人脸大角度下可能轻微变形(与 Apple 同款问题)。

## 5. 后续可做

- **重拍连主体背后一起重新生成**:把"新机位下主体让开的那块"也当洞,落定时跑 MI-GAN ⇒ 无论原填充模式如何,重拍后背后都是新鲜生成(更贴近 Apple)。
- 向画框外**主动 outpaint 扩展**(对应 Apple 的 Extend),而非仅补移出的边。
- 主体发光描边等可供性信号。
